## 1. Visual Theme & Atmosphere

비케이브 양식은 **차분한 권위(quiet authority)**를 지향합니다. 화려한 색이나 그래디언트 없이, 깊은 틸 그린(`#264148`)과 슬레이트(`#718790`)·옅은 표면 그레이만으로 구성해 — 보고 내용(숫자·표·차트)이 유일한 주인공이 되게 합니다. 결과물은 컨설팅 펌의 경영 보고서에 가깝습니다: 절제되고, 밀도 높고, 데이터가 스스로 말하게 하는 톤.

표지와 섹션 전환장은 **다크 틸 풀블리드**로 처리하고, 그 위에 **가는 흰 가로줄(1px)** 하나를 얹는 것이 이 템플릿의 시그니처입니다. 본문 슬라이드는 흰 배경에 플랫한 그레이 표면 카드·테두리 없는 표로 정보를 담아, 표지의 무게감과 본문의 가독성이 "다크-라이트 샌드위치"를 이룹니다.

컬러는 오직 **의미(semantic)에만** 허용합니다 — 상승은 녹색, 하락은 적색, 그 외 UI는 전부 무채(틸·그레이). 데이터 비교 차트의 다이버징 막대만 채도를 낮춘 적/녹(`#c75d55`/`#3f9b74`)으로 톤을 맞춥니다.

**Key Characteristics:**
- 다크 틸(`#264148`) 모노크롬 — UI는 무채, 색은 데이터 의미 전용
- 표지·섹션 전환장 = 다크 풀블리드 + 가는 흰 가로줄(시그니처)
- Pretendard 단일 패밀리 (Display부터 캡션까지, 별도 디스플레이 폰트 없음)
- 테두리 없는 플랫 테이블 + 옅은 그레이 표면 카드, 섀도 0
- 상단 3px 액센트 바를 단 KPI 카드 / 좌측 4px 액센트 바를 단 콜아웃
- 8px 그리드, 라운드 절제(카드 12–16px, 필 30px)

## 2. Color Palette & Roles

### Primary (브랜드)
- **B.CAVE Teal** (`#264148`): 핵심 액센트 — 제목·키커·표지/전환장 배경·KPI 상단 바·필 활성. (PPT 테마 dk2 `#0E2841` 계열의 슬라이드 적용값)
- **Slate** (`#718790`): 보조 액센트 — 차트 보조 막대·서브 헤딩·중간 강조
- **Surface Mist** (`#DEE2E3`): 칩·필·표면 틴트

### Background & Neutrals
- **White** (`#FFFFFF`): 본문 캔버스·카드 표면
- **Mist BG** (`#F4F6F7`): 보조 배경·콜아웃 표면
- **Line** (`#E6EAEB`) / **Line2** (`#CFD9DB`): 구분선·표 경계(최소)
- **Text** (`#16262C`): 본문·제목 (순흑 회피)
- **Text2** (`#5C6B70`): 설명·메타 / **Text3** (`#97A4A8`): 캡션·페이지번호

### Semantic (데이터 전용 — UI엔 쓰지 않음)
- **Up Green** (`#14AE5C`): 상승·성장·긍정
- **Down Red** (`#EC221F`): 하락·역성장·경고
- **Diverging** (탈채도): 적 `#C75D55` / 녹 `#3F9B74` — YoY 비교 막대 (순색 회피로 보고 톤 유지)
- **Link Blue** (`#2F70E8`): 링크·정보 (PPT 원본의 `#007AF9` 슬라이드 강조 대응)

### 표지/전환장 다크 위 텍스트
- 흰색 `#FFFFFF` 본문 / 하이라이트 `#BFD7DB`(밝은 틸) / 서브 `#C9D6D9` / 가로줄 `rgba(255,255,255,.55)`

### Gradient
양식은 그래디언트를 쓰지 않습니다. 다크 표지의 라디얼 틴트가 필요하면 틸 동계열 12% 이하로만 — 플랫이 기본.

## 3. Typography Rules

### Font Family
**Pretendard (Variable)** 단일 — Display·Heading·Body·Caption 전부. 별도 영문 디스플레이 폰트를 섞지 않습니다(원본 PPT 가이드가 Pretendard Black/Bold/…를 명시).
- CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable.min.css`
- 폴백: `'Pretendard', system-ui, sans-serif`
- 한글 줄바꿈 보호: `word-break: keep-all`

### Hierarchy (슬라이드 — clamp 반응형)
| 역할 | 크기(clamp) | 굵기 | 비고 |
|------|------|------|------|
| Display(표지) | `clamp(2.6rem,9vw,7.5rem)` | 800 | 다크 위 흰색, line-height ~1.05 |
| 슬라이드 제목 h2 | `clamp(1.3rem,3.4vw,2.5rem)` | 700–800 | letter-spacing −.02em |
| 섹션 헤딩 h3 | `clamp(1rem,2vw,1.5rem)` | 700 | accent2 색 |
| 본문 | `clamp(.8rem,1.35vw,1.05rem)` | 500 | line-height 1.5–1.6 |
| 캡션·출처 | `clamp(.66rem,1vw,.85rem)` | 600 | text3 |
| 키커(아이브로우) | small | 700 | letter-spacing .18em, 대문자, 앞에 액센트 가로 라인 |

### Principles
Pretendard Medium(500)을 본문 기본으로, 강조는 700–800으로만 단차를 줍니다(이탤릭·언더라인 지양). 숫자는 `font-variant-numeric: tabular-nums`로 정렬해 표·KPI에서 자릿수가 흔들리지 않게 합니다.

## 4. Component Stylings

### 표지 (Cover)
- 배경 `#264148` 풀블리드, 텍스트 흰색
- 제목 위 **가는 흰 가로줄**(`1px`, 폭 `min(46ch,62%)`, `rgba(255,255,255,.55)`) — 시그니처
- 상단 작은 배지(라운드 30px, 반투명 흰 테두리) + 하단 메타 행(순매출·소진율 등 핵심 수치) + 플로우 스트립(① → ② → ③ 칩)

### 섹션 전환장 (Divider)
- 표지와 동일한 다크 틸 풀블리드 + 키커(밝은 틸) + 큰 질문/선언 문장 + 플로우 스트립(현재 단계 `.on` 활성 = 흰 배경/틸 텍스트)

### KPI 카드
- 흰 표면 + 1px Line 테두리 + 라운드 16px + **상단 3px 틸 액센트 바**
- 라벨(대문자 small·text3) → 값(700·큰 숫자) → 델타(녹/적 small). 섀도 없음

### 데이터 테이블 (플랫)
- 헤더: 우측 정렬·700·text3, 하단 1.5px Line2 경계 / 첫 열 좌측 정렬
- 셀: 1px Line 하단선만, 마지막 행 무선. 강조 행은 Surface(`#DEE2E3`) 틴트
- 숫자 `tabular-nums`, 상승 `.pos`(녹)·하락 `.neg`(적)

### 콜아웃 / 노트
- 좌측 4px 틸 바 + Mist BG, 라운드 8px. 경고는 좌측 바·배경을 적색 계열로

### 칩 / 필 / 배지
- 필: 라운드 30px, 1.5px Line2 테두리(또는 틸 채움). 칩: Surface 배경·틸 텍스트·라운드 7px

### 차트 (CSS·SVG, zero-dep)
- 가로 막대: 트랙 `#EDF1F2`, 채움 틸(`accent`)·슬레이트(`mid`)·옅은 그레이(`muted`)
- 다이버징(YoY): 탈채도 적/녹, 중앙 축선 Line2, 이름 옆 절대값 병기 가능
- 라인: 실선 틸 + 전년 점선(`#C2CDD0`, dasharray `3 7`) + 끝점 라벨, 값 기반 nice-scale Y축
- 막대 비례는 항상 값과 일치(더 큰 값이 더 긴 막대) — 시각 왜곡 금지

### 마감장 (Closing)
- 다크 틸 풀블리드 + "감사합니다"/핵심 한 줄. 원본 PPT의 `E.O.D` 패턴

## 5. Layout Principles

- 8px 그리드. 슬라이드 패딩 `clamp(1.4rem,4vw,4rem)`, 블록 간격 `clamp(.6rem,1.8vw,1.5rem)`
- 본문 컨테이너 `max-width:~1180px`(상세/데이터 장은 ~1280px) 중앙 정렬
- 카드 그리드: KPI 4열, 프레임/전략 2–3열 — 좁아지면 2열 → 1열
- 본문 좌측 정렬(제목만 좌측 키커와 정렬), 표·리스트 좌측 정렬. 데드 스페이스는 `align-content` 재분배

## 6. Depth & Elevation

비케이브 양식은 **완전 플랫**입니다 — 카드 섀도·호버 리프트·플로팅 없음. 깊이는 오직 색으로: 다크 섹션은 후퇴, 라이트 본문은 전진, 그레이 단계(`#F4F6F7`→`#E6EAEB`→`#CFD9DB`→`#718790`)로 상태 차이를 표현. 유일한 "그림자"는 1px 구분선과 접근성 포커스 링.

## 7. Do's and Don'ts

### Do
- 제목·키커·액센트는 B.CAVE Teal `#264148` (순흑·순색 회피)
- 표지·전환장은 다크 풀블리드 + 가는 흰 가로줄 1개
- Pretendard 단일 패밀리, 본문 weight 500·강조 700–800
- 색은 데이터 의미에만 — 상승 녹·하락 적, 그 외 UI는 무채
- 표는 테두리 최소·플랫, 숫자 tabular-nums
- 막대 길이는 값에 비례(시각 정직성)

### Don't
- 카드 섀도·호버 리프트·그래디언트 UI 금지
- UI 요소에 브랜드 외 색(보라·형광 등) 도입 금지
- 제목 밑줄 강조선 금지(여백·배경색으로 대체)
- 본문 가운데 정렬 금지(제목만 예외)
- 다크 위 저대비 텍스트(밝은 회색) 금지 — 다크엔 흰/밝은 틸
- 디스플레이용 별도 영문 폰트 혼용 금지(Pretendard로 통일)

## 8. Responsive Behavior

- 전 타이포·간격 `clamp()` — 1920/1440/1280 가로, 720/900/1080 세로 전부 1뷰포트에 맞춤
- 세로 짧을 때(≤700/600/500px): 패딩·폰트 축소, 부가 요소(닷·캡션) 숨김
- 좁을 때(≤860/600px): KPI 4→2열, 인사이트 2열→1열, 표 가로 스크롤 회피 위해 열 축약
- 720p 프로젝터 우선: 밀도 높은 데이터 장은 `@media(max-height:768px)`에서 폰트·패딩 한 단계 더 축소

### Iteration Notes
1. 한 번에 한 컴포넌트, 이 문서의 hex를 직접 인용
2. "너무 화려하면" 무채로 — UI 색은 틸·그레이뿐, 색은 데이터에만
3. 다크 장(표지·전환·마감)과 라이트 장(본문)의 샌드위치 유지
4. 숫자는 항상 tabular-nums + 막대는 값에 비례(시각 정직성)
5. 1뷰포트 초과 시 분할 — 폰트 축소보다 슬라이드 분리 우선
